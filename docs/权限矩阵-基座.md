# 权限矩阵基座

## 同步命令

从 `backend/` 执行：

```bash
python main.py sync-permissions --env=dev
```

同步内容来自：

- `backend/app/scripts/data/sys_role.json`
- `backend/app/scripts/data/sys_menu.json`
- `backend/app/scripts/data/sys_role_menu_permissions.json`

同步逻辑按角色编码和菜单权限/路由幂等补齐，不删除已有人工配置。

## 基础角色

| 角色编码 | 角色 | 默认数据范围 |
| --- | --- | --- |
| `ADMIN` | 老板/系统管理员 | 全部数据 |
| `HQ_OPS` | 总部运营 | 全部数据，敏感字段另行授权 |
| `FINANCE` | 财务/收款复核 | 全部财务数据，个人隐私另行授权 |
| `STORE_MGR` | 店长 | 本部门及以下 |
| `SALES` | 销售 | 仅本人 |
| `MATCHMAKER` | 服务红娘 | 仅本人 |
| `RECEPTION` | 前台/接待 | 本部门 |
| `SCREEN_ADMIN` | 大屏管理员 | 本部门 |
| `AUDITOR` | 审核员 | 本部门 |

## 落地边界

- `AuthPermission([...])` 继续负责菜单/API 权限。
- 当前 `module_miailove` 前端页面尚未实现，业务菜单先作为隐藏权限占位；实现对应 `frontend/src/views/module_miailove/...` 页面后，再逐个开放菜单显示。
- 具体业务对象的数据范围在对应模块内继续叠加业务归属过滤。
- 手机号、身份证、证明材料、合同影像、深访录音、完整导出等敏感动作必须走独立权限码与审计。
