# 云支付集成说明

## 参数配置

云支付密钥统一维护在「系统管理 - 参数管理」：

| 参数键 | 说明 |
| --- | --- |
| `cloudpay.b_app_id` | 云支付分配给开发者的应用 ID |
| `cloudpay.private_key` | 请求报文 RSA2 加签私钥，PKCS#8 格式 |
| `cloudpay.public_key` | 云支付返回报文 RSA2 验签公钥 |

固定配置写在代码中：正式网关 `https://ecogateway.alipay-eco.com/gateway.do`、`version=1.0`、`charset=UTF-8`、`sign_type=RSA2`。

## 门店映射

- `cp_mid` 使用启用的最顶级门店编码，即 `sys_dept.parent_id is null` 的门店 `code`。
- `cp_store_id` 使用本系统交易门店 ID，即接口入参 `dept_id` 对应的 `sys_dept.id`。
- 如果没有启用顶级门店、存在多个启用顶级门店、交易门店不存在或已停用，接口会返回明确错误。

## 后端接口

路由前缀：`/api/v1/cloudpay/trade`

| 接口 | 权限 | 说明 |
| --- | --- | --- |
| `POST /pay` | `finance:payment:pay` | 条码支付 |
| `POST /precreate` | `finance:payment:pay` | 交易预创建 |
| `POST /create` | `finance:payment:pay` | 小程序 JS 支付创建 |
| `POST /query` | `finance:payment:query` | 交易查询 |
| `POST /refund` | `finance:payment:refund` | 退款 |
| `POST /refund-query` | `finance:payment:refund` | 退款详情查询 |

## 异步通知

固定回调路径：

```txt
/api/v1/cloudpay/notify/trade
```

支付、预创建、小程序创建接口如果没有传 `notify_url`，后端会自动使用当前请求域名生成该回调地址并透传给云支付。

当前回调处理范围：

- 接收 JSON / form 格式通知。
- 使用 `cloudpay.public_key` 验签。
- 验签通过后记录原始通知日志。
- 返回纯文本 `success`，避免云支付重复重试。

当前回调暂不更新本地订单状态；等收款流水和业务订单表落地后，再在该入口接入订单状态更新。

## 请求约定

- 金额字段使用字符串元单位，例如 `"199.00"`。
- `out_order_no` / `out_request_no` 最长 32 位，只允许字母、数字、下划线。
- 第一版不落本地支付流水表，调用方负责保存业务订单和支付结果。
- 第一版异步通知只做验签、日志和 `success` 应答，后续收款模块落库后再接入业务更新。
